# Agent Working Agreement

Before each execution block:

1. Read `CONTEXT.md` and `PLAN.md`.
2. Restate internally which product purpose and acceptance gate the block serves.
3. Stay inside the assigned directory ownership; coordinate before editing shared root files.
4. Prefer deterministic, testable code over speculative abstraction.
5. Do not add paid-service requirements or secrets.
6. Add tests for behavior introduced in the block.
7. Report changed paths, commands run, failures, and remaining integration work.

Never weaken provenance, uncertainty visibility, consent controls, or print fidelity to make a demo appear successful.
