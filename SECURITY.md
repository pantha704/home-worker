# Security policy

Do not report suspected vulnerabilities in public issues while this project is private. Share a minimal reproduction privately with the repository owner, including the affected version and whether untrusted document content is required.

Never attach a real identity document, signature, medical record, private student submission, API key, or production database to a report. Use the synthetic fixtures in `fixtures/`.

Supported security fixes target the latest minor release. See `docs/threat-model.md` and `docs/operations-runbook.md` for controls and incident steps.
